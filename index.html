DragonMarkdown

A clean C# desktop editor with a folder tree, focused source editing, live preview, Mermaid diagrams, and professional export paths for Word and PDF.

Get releases View source

Workbench

Built around folders, files, and preview confidence.

01

Open a folder or one file

Start with a workspace tree for project writing, or open a single markdown file when the job is smaller.

02

Hide what you do not need

The editor and preview panes can be toggled independently while the file tree remains available.

03

Advanced markdown support

Tables, task lists, front matter, math, syntax highlighting, and Mermaid preview support are part of the workflow.

Exports

Documents you can hand off.

DragonMarkdown exports the active document to Word and PDF. Common Mermaid graph and flowchart fences render into diagram output instead of staying as raw code.

Word DOCX export path for team review and document workflows.
PDF Portable output with rendered markdown structure and diagram support.
Installers Release automation targets MSI, DMG, DEB, and RPM packages.

Release ready

GitHub Actions builds, tests, coverage, and installers.

The repository is configured for CI, release artifacts, checksums, and a packaging roadmap for signed native installers.
