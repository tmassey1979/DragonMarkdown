# DragonMarkdown v0.1.0.4 Release Notes

## Highlights

- Docs Health Center now reports broken links, missing images, unsupported Mermaid export cases, malformed front matter, orphan markdown files, dead assets, and duplicate heading anchors.
- Export Readiness and Export Studio basics validate documents before export, support page setup/header/footer settings, and batch export workspace markdown files to PDF.
- Writing intelligence now includes active document statistics, workspace statistics, backlinks, and a generated table-of-contents updater.
- Visual markdown helpers insert table, Mermaid, and image scaffolds into the active document.
- Git workspace status shows the current branch, changed file count, and untracked file count for opened repositories.

## Validation

- Run full tests with:

```powershell
dotnet test .\DragonMarkdown.slnx --configuration Release --no-restore
```

- Validate release artifacts with:

```powershell
.\build\release\validate-v0.1.0.4-artifacts.ps1 -ArtifactDir .\artifacts\installers
```
