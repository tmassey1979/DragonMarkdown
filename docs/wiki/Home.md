# DragonMarkdown

DragonMarkdown is a native desktop markdown editor and viewer built with C#, .NET, and Avalonia.

## What It Does

- Opens folders and individual markdown files.
- Shows a workspace tree for project files.
- Provides side-by-side editor and preview panes.
- Lets users hide editor or preview while keeping the file tree visible.
- Supports advanced markdown preview and export workflows.
- Exports active markdown documents to Word and PDF.
